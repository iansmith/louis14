- core/css/counters_attachment_context.cc — algorithm verified:
  * Type is a BITMASK (DetermineCounterTypeAndValue ORs increment/reset/set
    bits when one element declares multiple directives on the same name).
  * ProcessCounter:
      RemoveStaleCounters (pop entries whose origin's parent is not an
        ancestor of the entering element);
      if Type has kResetType         -> CreateCounter (push fresh entry);
      else                            -> UpdateCounterValue (apply
        CalculateCounterValue to topmost entry).
  * CalculateCounterValue:
      if IsSetOrReset(type)           -> return new value;
      else                            -> int32-saturated add of current+value.
  * CreateCounter (reset):
      if existing stack innermost entry's origin is the entering element OR
        a previous sibling of it    -> pop that innermost entry first;
      then push new CounterEntry{origin, value}.
  * UpdateCounterValue (increment/set):
      if stack empty or top entry is a containment nullptr -> CreateCounter
        with implicit instantiation value 0 first;
      mutate top entry's value via CalculateCounterValue.
  * RemoveStaleCounters: pop while top's origin.LayoutParentElement is NOT
    an ancestor (IsAncestorOf walks parent chain) of entering element;
    stop at containment-boundary nullptr.
  * RemoveCounterIfAncestorExists (in LeaveObject for reset counters):
      if the previous stack entry's origin is an ancestor of the one being
      left, pop the left one (ancestor counter wins inheritance).
  * GetCounterValues walks stack in reverse;
      only_last=true            -> innermost in-scope value;
      only_last=false           -> collect outermost..innermost (== counters());
      stops at containment nullptr.
  * EnterObject: process explicit directives via ProcessCounter, then
    MaybeCreateListItemCounter, then maybe push containment scope.
  * LeaveObject: pop reset counters via RemoveCounterIfAncestorExists,
    pop containment scope; page-counter default fallback.
  * MaybeCreateListItemCounter (Phase 3 — DEFER): ol/ul/li/menu/dir;
    seed from <ol start>/<ol reversed>/<li value>.
  * ElementGeneratesListItemCounter (Phase 3 — DEFER): true for
    HTMLOListElement / HTMLUListElement / HTMLLIElement /
    HTMLMenuElement / HTMLDirectoryElement.
  * CalculateInitialValueForReversed (Phase 4 — DEFER).
