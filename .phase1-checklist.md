## Phase 1 scope (additive only — Hard Rule 6)

New surface in `pkg/css/style.go`:

1. `type WillChange struct` — resolved value model. Fields mirror StyleWillChangeData:
   - `Values []string` — raw idents, in source order (for serialization parity).
   - `Longhands map[string]bool` — resolved longhand property names only,
     no aliases, no shorthands. (Mirrors `resolved_longhand_ids` bitset.)
   - `HasScrollPosition bool` — `will-change: scroll-position`.
   - `HasTransformProperty bool` — narrow: only the `transform` longhand named.
   - `HasAnyTransformProperty bool` — broad: any of
     transform/translate/scale/rotate/perspective/offset-path/transform-style/offset-position.

2. `func (s *Style) GetWillChangeData() *WillChange` — single source of truth.
   - Returns `nil` for `auto` / unset / empty.
   - Lowercases idents; strips whitespace.
   - Drops `auto` ident; keeps `scroll-position` separately.
   - Normalizes vendor-prefixed aliases:
     `-webkit-perspective` → `perspective`,
     `-webkit-transform`   → `transform`,
     `-webkit-mask-box-image-source` (Blink alias for `mask-border-source`) stays as itself.
   - Expands shorthand idents to their longhand component(s):
     - `mask` → `mask-image` (+ other `mask-*` longhands, of which `mask-image`
       and `-webkit-mask-box-image-source` are the SC-relevant ones in Blink).
     - `transition` → `transition-property` etc. (Blink stores expanded longhands.)
     - `font` → `font-family` etc.
     For Phase 1 we only need to handle the shorthand expansions that influence
     the will-change side-effect predicates (`mask` is the only critical one for
     the css-will-change WPT corpus).
   - Computes cached predicate flags at parse time.

3. Predicate accessors on `*Style` (also expose on `*WillChange` for unit-testability):
   - `HasWillChangeProperty(name string) bool` — equivalent to Blink's
     `HasWillChangeProperty(CSSPropertyID id)`. Operates on the resolved longhand set.
   - `HasWillChangeScrollPosition() bool`.
   - `HasWillChangeTransformProperty() bool` — narrow.
   - `HasWillChangeAnyTransformProperty() bool` — broad.
   - `WillChangeCreatesStackingContext(allowsZIndex bool) bool` — encodes the
     canonical 20-entry set from `computed_style.cc:1319`.

Phase 1 does NOT change any existing accessor, does NOT change any consumer in
pkg/layout / pkg/render. Phases 2–5 do the consumer rewiring. Phase 1 is the
substrate.
