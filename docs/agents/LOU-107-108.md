## The Gaps to Fix

The LOU-105 fix in `pkg/render/render.go:drawColumnRules` is directionally correct but has two gaps vs Blink's `box_fragment_painter.cc`:

### Gap 1: Scrollbar subtraction (LOU-107)
Blink subtracts scrollbar block-end when computing content-box bottom:
```cpp
LayoutUnit multicol_block_end_offset =
    converter.ToLogical(box_fragment_.ContentRect()).BlockEndOffset() -
    scrollbars.block_end;
```
Louis14's `cbBottom` computation doesn't subtract scrollbars. Fix: subtract scrollbar block-end from `cbBottom`.

### Gap 2: Per-row "last row" detection (LOU-108)
Blink uses `!items_until_last_row` (per-row loop knows iteration index):
```cpp
if (!items_until_last_row) {  // only stretch in the last row
    rule_length = std::max(rule_length, stretched_rule_length);
}
```
Louis14 uses `len(gg.MainGaps) == 0` as a proxy for single-row, which won't work for multi-row multicols with spanners. Fix: track whether we're painting the last row and only stretch there, matching Blink's per-row gate.
